# 家有新解

AI 家具选品与空间布局助手。**让心仪设计，适配你的家。**

本仓库是当前本地网站的源码与完整展示素材快照：React + Vite + Three.js、三间卧室、六张风格参考图，以及关联的JSON、PNG、SVG、蒙版与GLB模型均已纳入版本管理。

## 运行

需要Node.js 22.12+、npm和Git LFS。原始106 MB布局模型通过Git LFS保存，其余网站素材随普通Git文件同步。在仓库根目录执行：

```sh
git lfs install
git lfs pull
npm run setup
npm run dev
```

打开 http://127.0.0.1:5173/ 。首次安装依赖需联网；内置案例浏览在本机运行，无需API密钥、Blender或原电脑目录。

```sh
npm test          # 70项几何、数据、素材及动画检查
npm run build     # 生成 frontend/dist
npm run preview   # 预览构建；先结束占用5173的开发服务
```

进阶检查需先安装根目录开发工具：

```sh
npm ci
npm run test:reference
npm run test:home
```

浏览器检查需已启动网站及Chrome；可用JYXJ_STUDIO_URL、JYXJ_BROWSER_EXECUTABLE覆盖地址与浏览器路径。

## 当前流程

首页只有「自定义场景」入口，进入后从上到下排列：

1. **平面图解析**：卧室01、02、03可展开、收起、拖入解析区。依次定尺寸、描轮廓、解析门窗、生成3D空房；支持暂停、回看、重播、门扇开关与前墙透明。折叠时仅显示顶层文字，净面积约13.21、12.00、12.15㎡，默认房高2.8m。
2. **参考图解析**：可本地上传单张图片或选择六张示例。布局、家具、配色与材质三路并行展示：六套示例读取已保存的平面图、最终Graph、分割与单品图，L01另有24个真实GLB模型；配色在浏览器按当前图片取样。Graph采用底图与矢量层分离加载，卡片使用轻量缩略图；缺少模型或材质标注的步骤保持待接入。分割等计算在独立本地工具完成，网站只展示已准备的结果。
3. **最终布局生成**：前两项解析完成并播放结束后启用，三个成果图标汇入空房间，再载入L01已保存布局演示。默认约15.91 MB清晰版GLB，支持旋转、缩放、平移、重置、墙体切换与下载；7.9 MB轻量版和106 MB原始模型保留。当前没有按照任意输入房间在线重新求解布局。

/custom为主流程；旧/parse地址兼容同一页面。/bedroom、/party、/studio为保留的历史演示路由。旧Python/Blender重算项目未迁移，旧工作台指向8879/8880的链接不代表服务已经接入。

## 数据边界

- 平面图采用已校对的示例标注，比例尺与二维/三维几何实际计算；不是任意图片实时OCR。无标注时900mm门宽回退仍保留。尺寸为估算或建模假设，非现场实测。
- 卧室01净框3600×3800mm并扣除950×500mm缺口；卧室02为3000×4000mm；卧室03为2700×4500mm，前墙位置采用原图假设。
- 参考图主流程读取六张原图对应的已保存成果，包括SAM 3分割、人工Graph标注和可用的单品模型，不代表在线重跑推理。旧版初稿的蒙版与三维代理仅作对照；实际尺寸及面积未知，未套用卧室尺度。材质只记录可见外观和取样，不鉴定真实材料、品牌或隐藏结构。
- 自选图片仅在当前浏览器预览与取色，不上传到计算服务。SAM 3在网站之外的本地工具中运行；已计算的分割、蒙版、Graph和模型作为静态成果发布。

## 目录

- frontend/src/：页面、卡片动画、二维与三维组件。
- frontend/public/assets/：可直接读取的完整静态素材。
- data/：素材同步所需的明确输入和结构化记录。
- demo/P03-R01/、demo/P04-R01/：历史客餐厅展示模型与报价数据。
- scripts/：网站检查、参考数据工具和分享包脚本。
- docs/：最终布局、图片优化与Graph加载优化说明。

开发服务器只监听127.0.0.1。网站不包含SAM 3计算服务、调用入口或本机代理，不需要Python、CUDA及模型权重。原计算源码和界面备份单独保存在开发者本机的`本地计算工具/SAM3/`，不随网站构建或GitHub仓库发布；计算后只把审核过的成果导入`data/`并重新构建。
